## 4. Technical SEO Checklist Verification

- [x] **Canonical Domain**: Single official domain enforced at `https://www.adfrenzymedia.com`
- [x] **Non-WWW Redirects**: 301 redirect in `next.config.ts` from `adfrenzymedia.com` to `www.adfrenzymedia.com`
- [x] **Self-Referencing Canonicals**: All static pages, service pages, case study pages, and articles carry self-referencing canonical tags.
- [x] **Clean Sitemap**: `https://www.adfrenzymedia.com/sitemap.xml` generates all canonical URLs with zero redirect or hash fragment entries.
- [x] **Robots.txt**: `https://www.adfrenzymedia.com/robots.txt` allows all legitimate bots and points to the sitemap.
- [x] **JSON-LD Structured Data**:
  - `Organization` (Official name, logo, social links, contact point)
  - `WebSite` (Official name, URL)
  - `ProfessionalService` (Gurugram address, business category)
  - `Service` schema on all `/services/[slug]`
  - `FAQPage` schema on `/faq` and all `/services/[slug]`
  - `Article` schema on all `/insights/[slug]` and `/work/[slug]`
  - `BreadcrumbList` schema on all secondary and tertiary pages.
- [x] **Internal Linking Mesh**: Every article links to relevant services and case studies; every case study links back to services and `/work`; service pages link to related case studies and articles.
